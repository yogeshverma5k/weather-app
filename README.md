# 🌦️ Weather App

A simple and responsive Weather App built using **React.js**.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Shows current temperature
- ☁️ Shows weather condition
- 💧 Shows humidity
- 💨 Shows wind speed
- 📱 Responsive design
- 🎨 Weather-themed background

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- OpenWeatherMap API
- Vite

## 🚀 How to Run

```bash
npm install
npm run dev
